# Final Project

This repository contains our collaborative final project for CS 3338 Software Engineering Tools.

## Project Structure
- `docs/` - Project documentation
- `src/` - Source code
- `assets/` - Images and other media
- `tests/` - Testing files

## Instructions
1. Clone the repository to your local computer.
2. Open the project folder in Visual Studio Code.
3. Pull the latest changes before working.
4. Commit and push your changes when finished.

## Collaboration
Team members use GitHub and the project board to organize tasks and track project progress.
